# Berserk VPN v5.3 Admin Broadcast

این نسخه بر پایه v5.2 ساخته شده و قابلیت پیام همگانی را به پنل ادمین اضافه می‌کند.

## قابلیت‌ها

- 📢 پیام همگانی داخل پنل مدیریت
- انتخاب جامعه هدف:
  - همه کاربران غیر بن‌شده
  - فقط خریداران
  - کاربران بدون خرید
  - کاربران فعال ۷ روز اخیر
- پشتیبانی از پیام متنی
- پشتیبانی از عکس همراه کپشن
- پیش‌نمایش قبل از ارسال
- تایید نهایی قبل از ارسال
- ارسال تدریجی برای کاهش ریسک محدودیت تلگرام
- گزارش تعداد موفق/ناموفق
- ثبت لاگ ارسال‌ها در دیتابیس

## فایل‌های تغییر کرده

- admin.py
- db.py

## نصب

1. قبل از deploy بکاپ دیتابیس بگیر.
2. فایل‌ها را در GitHub جایگزین کن.
3. Commit کن.
4. Railway → Deploy Latest Commit.

## تست

پنل مدیریت → پیام همگانی → انتخاب جامعه هدف → ارسال متن یا عکس → تایید نهایی.
